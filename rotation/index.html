How the axes are calculated

Each theme is an equal-weight index of its stocks (daily returns averaged across names). B is the benchmark, SPY or RSP. Weekly points use the last close of each week.

  1. Relative strengthRSt = 100 × Pt / Bt
  2. Trend of relative strengthRt = EMA3( 100 × RSt / SMA10(RS)t )
  3. RS-Ratio (x-axis)RS-Ratiot = 100 + ( Rt − μ40(R) ) / σ40(R)
  4. Change in RS-RatioMt = EMA3( RS-Ratiot − RS-Ratiot−1 )
  5. RS-Momentum (y-axis)RS-Momentumt = 100 + ( Mt − μ40(M) ) / σ40(M)

SMA10 = 10-week simple average. EMA3 = 3-week exponential average (α = 0.5). μ40 and σ40 = mean and standard deviation over the last 40 weeks.

Reading it. 100 is neutral on both axes. One point is one standard deviation of the theme's own history, so themes are comparable. RS-Ratio above 100: the theme is beating the benchmark by more than its recent trend. RS-Momentum above 100: that lead is widening.

Quadrants. Leading: both above 100. Weakening: RS-Ratio above, RS-Momentum below. Lagging: both below. Improving: RS-Ratio below, RS-Momentum above. Heading is the direction of the latest weekly move.

Don't chase Many names already near 52-week highs.

Avoid for now Broad selling across the group this week.
