# Theme Radar

Thematic equity research and the baskets that track it. Live at https://theme-radar.github.io

- Site output sits at the repo root and is served by GitHub Pages.
- `_src/` holds the builder (`build.py`) and the research content (`content/`).
- Rebuild: `python3 _src/build.py <radar_output_dir> . --asof YYYY-MM-DD --base https://theme-radar.github.io`
